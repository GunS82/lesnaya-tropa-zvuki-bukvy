# Лесная тропа знаний: звуки, буквы и алфавит

Третья отдельная браузерная игра для 2 класса по теме учебника «Звуки, буквы и алфавит» (часть 1, с. 78–87). На карте 18 заданий в трёх зонах: лаборатория звуков, алфавитная тропа и город больших букв. Страница 88 вынесена в дополнительную проверку после финиша.

**Играть онлайн:** <https://guns82.github.io/lesnaya-tropa-zvuki-bukvy/>

## Запуск

Откройте `index.html` в браузере. Если браузер ограничивает работу локальных файлов, запустите в этой папке:

```powershell
python -m http.server 8080
```

Затем откройте `http://127.0.0.1:8080/`. Для проверки данных и правил:

```powershell
node js/check-logic.js
```

Игра работает без сервера, базы данных и сборщика. Прогресс хранится в `localStorage` под собственным ключом `forestSoundsAlphabetProgress` и не смешивается с двумя предыдущими тропами.

## Что внутри

- Звуки всегда записаны в квадратных скобках; буквы показаны без скобок.
- Звуковые цепочки, поиск общего звука, замена звука и узнавание слова по звучанию.
- Алфавитная лента из 33 букв, пропущенные буквы, сортировка слов и словарная полка.
- Заглавные и строчные буквы, имена собственные, разделение слитного предложения.
- Неоднозначное слово «Владимир» принимается и как имя, и как название города.
- Финальная «Башня букв» из 12 вопросов и отдельная проверка из восьми случайных вопросов после финиша.
- Дополнительное задание о палиндромах после алфавитного шифра можно пропустить.

Слова по алфавиту можно перетаскивать между полкой и целевой областью, менять местами и проверять кнопкой. Нажатие карточки перемещает её между областями — это сохраняет удобное управление без перетаскивания. Для сортировки используется локальная копия [SortableJS](https://github.com/SortableJS/Sortable); лицензия MIT находится в `js/vendor/SORTABLE-LICENSE.txt`. На карточках выделена буква, по которой слова различаются.

Иллюстрации в `assets/scenes/` — сжатые JPEG. Текст задания и ответ находятся в интерфейсе, а не на картинке. Если иллюстрация не загрузится, интерфейс покажет эмодзи.
